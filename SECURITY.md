# 🔒 Security policy

## Supported versions

Only the [latest release](https://github.com/kowo-dev/Shelfy/releases/latest) receives security fixes. Keep your instance up to date as explained in [Updates](docs/self-hosting.md#updates).

## Reporting a vulnerability

Please do not open a public issue. Report it privately on GitHub instead: [report a vulnerability](https://github.com/kowo-dev/Shelfy/security/advisories/new).

Include the version you run, shown at the bottom of the account menu, and the steps to reproduce. A fix ships as a patch release, and you are credited in its notes if you wish.
